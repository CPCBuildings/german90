# German 90 v3

A static offline-capable German course PWA. No API key, server, account, or paid tutor required.

## Deploy to existing GitHub Pages repository

Upload the **contents** of this folder to the root of your `german90` repository, replacing old `index.html`, `manifest.webmanifest`, `sw.js`, and icons. Keep Pages configured for `main` / `(root)`.

Open the published HTTPS site in iPhone Safari → Share → Add to Home Screen.

## Important limitations

- Course: 15 units × 6 deliberately sequenced sessions = 90 sessions. This is a beginner foundation, **not** a guarantee of B1 proficiency in 90 days.
- Vocabulary: 180 unit entries (some repeat across units); sessions build from teaching to pronunciation, grammar, recall, listening and guided speaking.
- Speech synthesis is browser-generated German audio; it is not a human recording and requires a German voice installed on your device.
- The app does **not** directly integrate with ChatGPT Voice, score your speech, or sync progress with ChatGPT. Use Copy oral lesson → Open ChatGPT → Paste → Voice.
- Progress is saved locally on each device. Use Export/Import for backup or migration.
- When updating an installed PWA, reload it while online to refresh cached files.
